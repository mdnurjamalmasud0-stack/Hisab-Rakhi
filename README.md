# হিসাব রাখি — V1

মোবাইল-ফার্স্ট বাংলা হিসাব অ্যাপের প্রথম স্টার্টার প্রজেক্ট।

## V1-এ আছে
- সাইন আপ
- লগইন
- লোকাল SQLite ডাটাবেস
- কাস্টমার যোগ
- কাস্টমারের ফটো গ্যালারি থেকে যোগ
- পাওনা/পরিশোধ লেনদেন
- লেনদেনের ইতিহাস
- ড্যাশবোর্ড
- রিপোর্ট
- সেটিংস/লগআউট

## চালানোর নিয়ম
1. Flutter SDK ইনস্টল করুন।
2. এই ফোল্ডারে `flutter pub get` চালান।
3. Android ফোনে USB debugging চালু করে `flutter run` দিন।
4. প্রথমে একটি অ্যাকাউন্ট সাইন আপ করুন।
5. কাস্টমার > + > ফটো যোগ করুন।

নোট: এই V1 অফলাইন/লোকাল ডাটাবেস ভিত্তিক। OTP, অনলাইন ব্যাকআপ, WhatsApp/SMS API, PIN lock এবং Play Store release পরের ধাপে যোগ করা যাবে।
